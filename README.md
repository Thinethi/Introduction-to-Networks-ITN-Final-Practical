# Cisco Networking Academy – Introduction to Networks (ITN) Final Practical

## 📌 Overview

This project showcases the successful completion of the **Cisco Networking Academy – Introduction to Networks (ITN) Final Practical**. It demonstrates the design and implementation of a fully functional enterprise network using industry-relevant networking concepts and configurations.

---

## 🚀 Project Description

In this hands-on assessment, a complete enterprise-level network was designed, configured, and tested. The project focuses on applying theoretical knowledge to real-world networking scenarios, ensuring efficient communication, scalability, and security.

---

## 🛠️ Key Features & Implementation

### 🔹 IP Addressing (VLSM)

* Designed structured IP addressing using **Variable Length Subnet Masking (VLSM)**
* Optimized subnet allocation for efficient IP usage

### 🔹 Routing Configuration

* Implemented **static routing** across multiple routers
* Ensured seamless end-to-end connectivity between networks

### 🔹 Network Services

Configured essential services including:

* **DHCP** – Automatic IP address assignment
* **DNS** – Domain name resolution
* **Web Server** – Hosting web services
* **Email Server** – Communication support

### 🔹 Security Implementation

* Enabled **SSHv2** for secure remote access
* Applied secure login practices
* Configured session management controls

### 🔹 Backup & Reliability

* Performed configuration backups using **TFTP**
* Ensured network reliability and quick recovery options
